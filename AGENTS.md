# AGENTS.md

Этот проект — Telegram-бот для заполнения немецкой анкеты Bürgergeld. Основная цель бота — вести диалог с пользователем, валидировать ответы, собирать данные и генерировать PDF.

## Быстрый старт
- Точка входа: [src/index.js](src/index.js)
- Запуск: `npm start`
- Конфигурация берётся из `.env` в корне проекта
- Обязательная переменная для запуска бота: `TELEGRAM_BOT_TOKEN`
- Дополнительные переменные: `DEBUG_SKIP`, `ADMIN_CHAT_ID`

## Ключевые модули
- [src/bot/bot.js](src/bot/bot.js) — инициализация Telegraf, обработка команд и callback-запросов
- [src/bot/flow.js](src/bot/flow.js) — основная логика шага анкеты, навигации, пропуска и генерации PDF
- [src/forms/buergergeld/pages/allPages.js](src/forms/buergergeld/pages/allPages.js) — сборка списка всех полей и секций формы
- [src/services/validateAnswers.js](src/services/validateAnswers.js) — правила валидации ответов
- [src/storage/sessions.js](src/storage/sessions.js) — хранение сессий в памяти, без базы данных
- [src/pdf/renderPdf.js](src/pdf/renderPdf.js) — генерация PDF
- [src/ai](src/ai) — локальные подсказки и обработка полей без внешних AI-вызовов

## Важные проектные соглашения
- Проект использует ESM (`"type": "module"`). Сохраняйте импорты/экспорты в таком стиле.
- Бот работает по шагам. Изменения в логике переходов между полями лучше делать аккуратно, потому что они влияют на пользовательский сценарий и PDF.
- Поля формы определяются в файлах страниц внутри [src/forms/buergergeld/pages](src/forms/buergergeld/pages). Если добавляете/удаляете поле, проверьте связанные зависимости и валидацию.
- Состояние пользователя хранится в памяти; не добавляйте постоянное хранилище без явной необходимости.
- Для пользовательского ввода важны существующие правила валидации и сообщений об ошибках. Не ломайте текущее поведение без причин.
- Callback-данные и inline-клавиатуры уже имеют свои паттерны в [src/bot/flow.js](src/bot/flow.js); сохраняйте совместимость с ними.

## Что стоит учитывать при изменениях
- Локализация и тексты интерфейса в основном на русском и немецком; не меняйте их без необходимости.
- Для проверок полезно запускать бота локально и смотреть, как реагирует сценарий на реальные ответы.
- Сейчас нет отдельного набора тестов; после правок лучше прогнать приложение и проверить базовый сценарий.
